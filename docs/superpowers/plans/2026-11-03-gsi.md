# 接入 GSI(游戏状态接口)方案(大白话版)

日期:2026-11-03 · 状态:待确认,未动代码

## 一句话说清楚要干什么

让 Dota 自己告诉程序「现在是选人、策略时间还是已经进游戏了」,程序据此**自动出现、自动静默**。
技能池和谁选了什么,GSI 不提供,仍然靠现在的截图识别。

## 为什么要接

现在只能靠看画面判断阶段,有三个毛病:

1. 要一直截图才知道画面变了。截图每次 0.5–1.9 秒,频繁截会拖慢游戏。
2. 策略时间、进游戏、主菜单都只能靠「这不像选人界面」来排除,没法分清到底是哪个阶段。
3. 进游戏后悬浮窗还留在右下角,挡住小地图。

GSI 直接给出阶段、对局编号和时钟,这三个问题都能解决。

## GSI 是什么、怎么工作

- 在 Dota 安装目录的 `game/dota/cfg/gamestate_integration/` 里放一个配置文件。
- Dota **启动时**读这个文件,之后每隔零点几秒,把游戏状态以 JSON 发到配置里写的本机地址。
- 程序在本机开一个只收不发的小服务器接这些数据。

数据只在你自己的电脑里流转:Dota → 本机程序。不联网,不读游戏内存,也不往游戏里写任何东西。

## 用 GSI 做哪几件事

| 用途 | 用到的数据 | 效果 |
|---|---|---|
| 自动静默 / 恢复 | 游戏阶段 | 选人时显示;策略时间、进游戏后隐藏;下一局选人开始时自动恢复 |
| 分清是不是新的一局 | 对局编号 | 换局时清空记忆,比现在「技能对不上就算换局」更准 |
| 以后的自动扫描(本方案先不做) | 选人时钟 | 每人 7 秒、轮次间休 5 秒,可以算出「有人刚选完」的时刻,只在那时截图 |
| 以后的游戏内功能(本方案先不做) | 自己的英雄、技能、物品 | 你说的出装、技能搭配建议要用的数据 |

## 阶段怎么对应程序的行为

| GSI 阶段 | 程序做什么 |
|---|---|
| 不在对局里(主菜单等,没有阶段数据) | 隐藏悬浮窗,不截图 |
| 选人(`HERO_SELECTION`) | 显示悬浮窗,正常扫描 |
| 策略时间(`STRATEGY_TIME`) | 隐藏悬浮窗 |
| 加载、准备、游戏中(`WAIT_FOR_MAP_TO_LOAD`、`PRE_GAME`、`GAME_IN_PROGRESS` 等) | 隐藏悬浮窗,不截图 |
| 游戏结束(`POST_GAME`) | 隐藏;记忆清空,等下一局 |

另外两条规则,和有没有 GSI 无关:

- **你选满 5 件后**:不再推荐,清掉格子上的框,面板只显示「已选满」。
- **你手动打开过悬浮窗**:程序不跟你抢,不会自动再关一次(参考上游的做法)。

## 没装 GSI 时怎么办

GSI 是**可选功能**,默认不开。没开、或者开了但收不到数据时,退回纯画面判断:

- 连续 2 次判定为「不是选人界面」→ 隐藏悬浮窗。
- 你再按 Ctrl+Shift+S、并且画面是选人界面 → 恢复。

两种方式同时存在时,以 GSI 为准。

## 分几步做

每一步都能单独测,做完一步再做下一步。

### 第 1 步:收数据的本机服务器

- 程序启动时,在 `127.0.0.1` 上开一个端口,只接收 Dota 发来的数据。
- 配置文件里带一个随机口令,收到的数据口令不对就丢掉,防止别的程序冒充 Dota。
- 只监听本机地址,其他电脑连不上。

**做完的标志**:用造的 GSI 数据发过去,程序能正确读出阶段、对局编号和时钟;口令不对的被丢掉。

### 第 2 步:读懂 GSI 数据

- 把收到的 JSON 整理成「阶段、对局编号、时钟」三样。其他字段先不用。
- 数据缺字段、格式不认识时不报错,当作「不知道」处理。

**做完的标志**:用上游公开的真实抓包样本测试,各阶段都能读对。

### 第 3 步:写配置文件(需要你同意)

- 设置里加一个「启用 GSI」开关。打开时:
  1. 程序**只读**注册表和 Steam 的库列表,找到 Dota 安装位置;找不到就让你手动选文件夹。
  2. 弹窗告诉你:要往哪个路径写哪个文件、文件里写了什么。**你点确认后才写**。
  3. 提示你**重启 Dota**,配置才生效。
- 只写这一个文件,不改 Dota 的任何其他文件。关闭开关时,问你要不要删掉它。

**做完的标志**:在测试文件夹里写出的配置文件内容正确;没点确认时什么都不写。

### 第 4 步:自动静默

- 按上面的阶段表显示或隐藏悬浮窗。
- 换对局编号时清空记忆。
- 加上「你选满 5 件」和「连续 2 次不是选人界面」这两条后备规则。

**做完的标志**:用造的阶段序列(选人 → 策略时间 → 游戏中 → 结束 → 下一局选人)测试,显示和隐藏都对。

### 第 5 步:真机验证(需要你)

打一局自定义:启用 GSI、重启 Dota,从主菜单一直打到进游戏。看悬浮窗是否在策略时间消失、进游戏后不再挡小地图、下一局选人时自动出现。

## 合规

- 只用 Valve 官方提供的 GSI,只接收、不发送;不读游戏内存,不往游戏里注入东西,不模拟按键。
- 只写 Dota `cfg/gamestate_integration/` 下这一个文件,写之前必须你明确同意。
- 数据不出本机,不上传。
- 合规扫描脚本里加一条检查:程序只能监听 `127.0.0.1`,不能监听所有网卡。
- 自己玩时 GSI 只给你自己的信息,拿不到对手的隐藏信息。

## 要先在真机上确认的事

这几点我没法在你电脑上离线确认,第 5 步会顺便验证:

1. **技能征召模式下阶段名是否和上面一致**:上游的实测是一致的,但我们自己还没抓过。
2. **是否需要启动参数 `-gamestateintegration`**:有的教程说要加,有的说不用。
3. **端口有没有被占用**:被占用时自动换一个,并重写配置文件。

## 这一轮先不做的

- 用时钟自动触发扫描(等你说要做自动化时再做)。
- 游戏内出装、技能建议(你以后的收费功能)。
- 观战模式。

## 风险

- **没有 Valve 的书面保证**:GSI 是官方公开功能,正常使用不属于作弊;但没有找到 Valve 明确说「第三方工具可以用」的声明。做成可选、默认关闭,就是为了让用户自己决定。
- **收费功能上线前**:最好再查一次 Valve 当时的政策,收费会让它看起来更像商业工具。
- **Dota 更新后数据格式可能变**:读数据时字段缺了就当作「不知道」,退回画面判断,不会崩。
